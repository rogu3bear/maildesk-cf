# Maildesk v0.1.1

This source-template patch keeps the intended Cloudflare context consistent
through routing inspection, sender-domain planning and closeout.

- Routing inspection and sender-domain plan refresh reject a selected profile
  belonging to a different desired account before any provider read or plan.
- Closeout passes its explicit `--cfctl` executable to production preflight as
  well as sender-domain checks, overriding an unrelated ambient installation.
- Sender-domain refresh accepts `--desired-state` or
  `MAILDESK_DESIRED_STATE_PATH` to resolve the intended account.

The published v0.1.0 source remains unchanged. Local regression checks do not
establish provider authorization, deployed runtime or mailbox delivery.
